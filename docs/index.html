      What the backtest found

      Plain DCA is hard to beat

      $500 a month from Sep 2017 to Sep 2026. What each $100 of budget grew to:

      • Plain daily DCA $533 baseline
      • AHR999 tilt, unspent money saved for later $556 +4%
      • AHR999 tilt, monthly limit (the default below) $460 −14%

      Buying more when AHR999 is low is a small tilt, not a timing tool. It only helped when the money it skipped could be spent later, and it lost when that money expired each month.

      Every strategy uses only data known on each simulated day. Budget left unspent counts as cash, so all strategies are compared on the same money.
